# Smoke-сценарии Philosofidget

Пять ручных сценариев для агента, управляющего Android-эмулятором через
скриншоты, дерево интерфейса, нажатия, свайпы и системные кнопки.

## Подготовка и порядок запуска

- Использовать отдельный тестовый эмулятор Android 8.0 / API 26 или выше
  с лаунчером, поддерживающим закрепление виджетов, например Pixel Launcher.
  Для сценария 05 нужны свободное место на рабочем столе, доступ в интернет
  и достаточный заряд батареи (отключить энергосбережение).
- Установить тестируемую сборку `ru.snakelord.philosofidget`.
  Приложение в списке приложений называется **Philosofidget**.
- Перед всей серией удалить старые виджеты Philosofidget с рабочего стола,
  затем через системные настройки очистить хранилище только этого приложения.
  Это удалит тестовые настройки; не выполнять на устройстве с пользовательскими данными.
- Выполнять файлы 01–05 по порядку, не очищая данные между ними.
  Для отдельного запуска выполнить предусловия выбранного сценария.
- Открывать приложение через его значок. Искать элементы по видимому тексту
  и дереву интерфейса, без фиксированных координат. Регистр текста кнопок
  может отличаться. Прокручивать настройки свайпом внутри списка под кнопкой
  «Выбрать тему цитат»: превью и нижняя кнопка находятся вне этого списка.
- После действия дождаться стабильного экрана, максимум 5 секунд.
  Для сетевой загрузки в сценарии 05 отвести до 60 секунд. Это лимиты прогона,
  а не гарантированные сроки работы приложения. Не повторять нажатие во время ожидания.
- При перезапуске открыть системную страницу приложения, нажать
  «Остановить» / «Принудительно остановить», подтвердить и снова открыть
  Philosofidget через значок. Не очищать данные и не переустанавливать приложение.

## Что фиксировать

Для каждого сценария записать ID, версию сборки, Android/API, лаунчер,
статус **PASS / FAIL / BLOCKED**, последний выполненный шаг и фактический
результат. PASS допустим только при выполнении всех проверок. При расхождении
сохранить скриншот и доступное дерево интерфейса; при падении — также logcat,
если инструмент агента его предоставляет. Сломанные предусловия отмечать BLOCKED.
Недоступный API или лаунчер не считать успешным прохождением. Если причина
сбоя неизвестна, зафиксировать FAIL с наблюдением, не списывать его автоматически на сеть.

## Ограничения проверок

Превью всегда содержит одну русскую цитату и автора «Энтони Роббинс».
Выбор English не переводит превью. Каталог из 18 тем моковый: выбор сохраняется,
но не фильтрует сетевые цитаты. Не проверять соответствие цитаты выбранной теме.
Текст сетевой цитаты случаен, автор может отсутствовать. Изменения оформления
сохраняются нижней кнопкой, тема сохраняется отдельно при подтверждении выбора.
Удаление последнего виджета очищает настройки оформления: не удалять его
во время проверки сохранения в сценарии 05.
