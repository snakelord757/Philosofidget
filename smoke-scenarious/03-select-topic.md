# SMOKE-03. Выбор темы и сохранение после перезапуска

**Предусловия:** открыт экран настроек, текущая тема «Не выбрана».
При отдельном запуске очистить тестовые данные по README. Сеть не требуется.

1. Нажать «Выбрать тему цитат».
   **Ожидание:** экран «Темы цитат», кнопка «Назад», список с «Жизнь»,
   «Мудрость», «Любовь» в начале.
2. Прокрутить список вниз до «Душевное спокойствие» и нажать эту строку.
   **Ожидание:** диалог «Выбрать тему?» с текстом
   «Текущая тема для цитат: «Душевное спокойствие»» и кнопками «Отмена», «Выбрать».
3. Нажать «Выбрать» в диалоге.
   **Ожидание:** диалог и экран списка закрылись; на экране настроек отображается
   «Тема цитат: Душевное спокойствие».
4. Не нажимая нижнюю кнопку добавления/сохранения виджета, принудительно
   остановить приложение и открыть снова способом из README.
   **Ожидание:** тема по-прежнему «Душевное спокойствие».
5. Снова нажать «Выбрать тему цитат».
   **Ожидание:** кнопка работает после возврата и перезапуска, список открывается.
6. Нажать экранную кнопку «Назад».
   **Ожидание:** открыт экран настроек, выбранная тема не изменилась.

**Результат:** подтверждённая тема сохраняется независимо от настроек виджета.
Оставить тему «Душевное спокойствие» для SMOKE-04.
