# SMOKE-04. Отмена выбора и возврат

**Предусловия:** экран настроек показывает «Тема цитат: Душевное спокойствие».
Для отдельного запуска выбрать и подтвердить эту тему по шагам 1–3 SMOKE-03.
Сеть не требуется.

1. Нажать «Выбрать тему цитат», при необходимости прокрутить список к началу
   и нажать «Жизнь».
   **Ожидание:** диалог «Выбрать тему?» содержит «Текущая тема для цитат: «Жизнь»».
2. Нажать «Отмена».
   **Ожидание:** диалог закрыт, экран «Темы цитат» остаётся открыт.
3. Нажать экранную кнопку «Назад».
   **Ожидание:** на экране настроек всё ещё «Тема цитат: Душевное спокойствие».
4. Снова открыть выбор темы и нажать «Мудрость».
   **Ожидание:** открылся диалог с названием «Мудрость».
5. Выполнить системное действие Android «Назад» один раз.
   **Ожидание:** закрыт только диалог; список тем остаётся на экране.
6. Выполнить системное действие «Назад» ещё раз.
   **Ожидание:** открыт экран настроек, тема осталась «Душевное спокойствие».
7. Принудительно остановить приложение и открыть снова способом из README.
   **Ожидание:** отменённые темы не сохранились, отображается
   «Тема цитат: Душевное спокойствие».

**Результат:** отмена кнопкой и системный возврат не меняют сохранённый выбор.
