# SMOKE-02. Изменение превью

**Предусловия:** выполнен SMOKE-01; при отдельном запуске очистить тестовые данные
по README и открыть приложение. Виджет ещё не добавлен. Сеть не требуется.

1. Выключить «Отображать автора цитаты (если есть)».
   **Ожидание:** «Энтони Роббинс» исчезает из превью, текст цитаты остаётся.
2. Включить тот же переключатель.
   **Ожидание:** автор снова виден.
3. Найти «Размер текста цитаты» и перетащить ползунок к левому краю (11).
   **Ожидание:** текст цитаты в превью заметно уменьшается по сравнению с исходным.
4. Перетащить этот ползунок к правому краю (30).
   **Ожидание:** текст увеличивается до исходного размера. Проверять подпись
   ползунка при перемещении, а не только постоянные метки границ 11 и 30.
5. Найти «Положение текста цитаты», открыть список и выбрать «По центру».
   **Ожидание:** строки цитаты выровнены по центру превью.
6. В том же списке выбрать «Слева».
   **Ожидание:** строки цитаты снова выровнены по левому краю.
7. Вернуться к настройке языка, открыть список и выбрать «English».
   **Ожидание:** список показывает English; русская цитата в превью не меняется.
8. Выбрать «Русский» в списке языка.
   **Ожидание:** значение снова «Русский», превью остаётся доступным.

**Результат:** переключатель, ползунок и списки управляют превью согласно назначению.
Не нажимать «Добавить на главный экран»; оставить экран открытым.
