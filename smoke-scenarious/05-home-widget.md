# SMOKE-05. Добавление виджета и сохранение оформления

**Предусловия:** выполнена подготовка README для виджета; на рабочем столе
нет виджетов Philosofidget. Открыт экран настроек, нижняя кнопка —
«Добавить на главный экран». Тема может быть любой.
При отдельном запуске начать с чистого тестового состояния по README.

1. Включить отображение автора, если оно выключено. Установить язык «Русский»,
   размер цитаты в правое крайнее положение (30), положение цитаты — «Слева».
   **Ожидание:** значения отображаются в настройках и соответствуют превью.
2. Нажать «Добавить на главный экран».
   **Ожидание:** лаунчер предлагает разместить виджет Philosofidget.
   Подтвердить размещение видимой системной кнопкой «Добавить» /
   «Добавить автоматически» (название зависит от лаунчера).
   Если лаунчер разместил виджет сразу, перейти к проверке рабочего стола.
   Если показано «Текущий лаунчер не поддерживает добавление виджета через приложение»,
   отметить BLOCKED и указать лаунчер.
3. Перейти на рабочий стол системной кнопкой Home, найти новый виджет.
   **Ожидание:** виджет размещён; в течение 60 секунд появилась непустая
   сетевая цитата. Сохранить скриншот для сравнения оформления в шаге 6.
   Не сравнивать цитату дословно с превью и не требовать автора:
   API может вернуть цитату без него. При пустом виджете зафиксировать скриншот
   и, если доступен, logcat с `workerError`; не считать пустой виджет успешным результатом.
4. Открыть Philosofidget через значок приложения.
   **Ожидание:** нижняя кнопка называется «Сохранить конфигурацию».
5. Установить размер цитаты в левое крайнее положение (11), положение текста
   цитаты — «По центру», выключить отображение автора.
   После каждого изменения дождаться обновления превью.
   **Ожидание:** превью содержит маленькую цитату по центру без автора;
   «Сохранить конфигурацию» доступна.
6. Нажать «Сохранить конфигурацию», затем перейти на рабочий стол.
   **Ожидание:** за 5 секунд оформление виджета обновилось: текст стал меньше
   и выровнен по центру, автор отсутствует. Сравнить со скриншотом шага 3.
7. Принудительно остановить приложение и открыть снова способом из README.
   **Ожидание:** переключатель автора выключен, положение цитаты — «По центру»;
   ползунок размера находится слева (11), превью соответствует этим значениям.
   Виджет остаётся на рабочем столе.

**Результат:** виджет добавлен, сохранённое оформление применяется и переживает
перезапуск приложения. Оставить виджет для осмотра результата; не ждать
периодического обновления цитаты — это отдельная длительная проверка.
